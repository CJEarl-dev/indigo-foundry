## The challenge
A self-directed project built to demonstrate a full design-to-launch workflow — starting from nothing and making every decision: brand, color, content, layout, and functionality.

## What we built
- Developed the full visual identity — color system, typography, and brand tone
- Selected and curated all imagery to match the brand aesthetic
- Built a custom lookbook-style layout for showcasing salon work
- Integrated StyleSeat for appointment booking
- Shipped a complete, production-ready site with no template starting point

## Outcome
A polished, fully functional salon website built entirely from scratch — demonstrating range across design, content, and development in a single project.
