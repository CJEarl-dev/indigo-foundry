Indigo Foundry — Studio Website

The marketing and portfolio site for Indigo Foundry LLC, a boutique web development studio based in metro Atlanta, GA.

Built with:

Astro + Tailwind CSS v4
Netlify (hosting + forms)
Content Collections for portfolio projects

Key features:

WCAG 2.2 AA compliant across all pages
100/100 Lighthouse scores (Performance, Accessibility, SEO, Best Practices) on production
Custom project portfolio with category filtering
Netlify Forms with success redirect
Fully custom copy, brand system, and component modifications

Live site: https://www.indigo-foundry.com
